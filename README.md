# F📘 API Testing Project – FakeStoreAPI

# 🔹 Project Overview

# This repository contains an API Testing project built using Postman with the FakeStoreAPI.

# It includes collections, environment variables, test cases, defect reports, and execution results for validating multiple endpoints.

# 

# 🔹 Modules Covered

# Products API – /products, /products/{id}, /products/categories, /products/category/{categoryName}

# 

# Carts API – /carts, /carts/{id}

# 

# Users API – /users, /users/{id}

# 

# Auth API – /auth/login

# 

# 🔹 Repository Contents

# FakeStoreAPI.postman\_collection.json → Postman collection with all requests

# 

# Test Cases.xlsx → Designed test cases (positive \& negative)

# 

# Defect Report.xlsx → Logged defects with severity, priority, and linked test cases

# 

# Test Execution Report.docx → Execution summary with pass/fail results

# 

# Result/ → Folder containing screenshots and supporting evidence

# 

# 🔹 Tools \& Environment

# Postman v10 for API testing

# 

# Windows 10 execution environment

# 

# FakeStoreAPI (public mock API)

# 

# 🔹 Key Highlights

# Positive and negative test scenarios executed

# 

# Defects logged for failed cases (error handling, cart ID, retrieval issues)

# 

# Execution statistics: 18 test cases, 12 passed, 6 failed, 4 defects raised

#
